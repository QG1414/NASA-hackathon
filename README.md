## Basic Info

This game was created for the **NASA Space Apps Challenge**.

It was developed in 2022.

## Game Info

It is a **tycoon-like 2D game** focused on discovering new planets and upgrading research stations.

The game can be played here:
https://steellotus.itch.io/space-observer

## Technology

The game was developed using **Unity** with the **C# programming language**.
